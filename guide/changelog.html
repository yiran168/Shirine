      #更新日志

      #v1.0.0 2026-09-24 正式发布

      #核心架构全面升级

      • Astro 5 + Cloudflare 全栈架构：
        • 前端全面基于 Astro 5 SSR 与 Svelte 5 构建，由 Cloudflare Pages 提供边缘极速交付。
        • 后端采用 Cloudflare Workers + Hono + Drizzle ORM，毫秒级响应并严格控制捆绑包体积（< 25MB）。
        • 数据持久化于 Cloudflare D1 分布式 SQLite，多媒体附件全面接入 Cloudflare R2 对象存储。

      #核心功能与亮点

      • Material 3 Expressive (M3E) 完整视觉系统：
        • 遵循 Google M3E 大圆角流体布局与层级阴影设计。
        • 内置 HCT 动态色彩空间算法，自定义主色相（0-360°）自适应推导全站色阶。
        • 搭载全新二次元 Chibi 芙宁娜 (Furina) 水元素无缝平滑循环 Loading 动效与交互。
      • 三级阅读权限控制与积分体系：
        • 支持公开、登录专属与积分解锁三级权限，附带毛玻璃密码锁与五彩纸屑解锁粒子动效。
        • 每日签到引擎支持固定点数与区间随机抽奖，防刷控制与交易流水追踪。
      • 50 款精美二次元 WebP 预设头像：
        • 全新生成 50 款完全独特的二次元动漫头像与对应高清缩略图，提供便捷网格弹窗选择器。
      • 沙箱隔离的 Pio Live2D 看板娘：
        • 深度优化 iframe 沙箱机制，彻底杜绝样式冲突；提供顶层常驻呼唤按钮与多语言自定义台词。
      • 全动态多源音乐播放器：
        • 深度支持本地曲目、R2 音频直链与 Meting 远端歌单（网易云、QQ 音乐、酷狗等）。
        • 引入音频元数据即时预载（preload="metadata"），彻底解决时长延迟与自定义曲目在前台生效问题。
      • AI 智能写作助手：
        • 深度集成大语言模型流式输出，支持思维链推理（Reasoning / Thought）折叠推演与超时异常保护。
      • 富媒体 Markdown 语法手册与一键直达：
        • 管理后台新增语法示例手册与右侧悬浮快速目录导航（TOC Jump Navigation），支持一键复制代码模板。
      • 无感人机验证与四语国际化：
        • 深度集成 Cloudflare Turnstile 智能验证。
        • 全站与控制台全面支持简体中文、繁体中文、英语、日语四语无缝切换。
