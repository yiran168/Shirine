      • #Shirine v1.0.0 正式发布

      发布日期: 2026年9月24日

      Shirine v1.0.0 是 Shirine 博客系统的全新里程碑。本次发布确立了基于 Astro 5 SSR + Cloudflare 全栈（Pages + Workers + D1 + R2）的现代化架构，深度实现 Material 3 Expressive (M3E) 设计规范，带来极致的视听动效、内容安全与全动态交互体验。

      #本次发布的重点特性

      #1. Astro 5 + Cloudflare 全栈架构

      • 全动态即时发布：前端采用 Astro 5 SSR，在 Cloudflare Pages 边缘节点高效渲染；后端采用 Cloudflare Workers + Hono + Drizzle ORM，毫秒级冷启动。
      • 分布式 D1 数据持久化：博文、动态、相册、用户积分与站点配置全部持久化存储于 Cloudflare D1 分布式数据库。
      • R2 对象存储与自定义域名：音频、相册与富媒体附件直连 Cloudflare R2，后台即可轻松绑定自定义公网域名。

      #2. Material 3 Expressive 设计规范与 HCT 动态色彩

      • 100% 遵循 Google M3E 大圆角流体布局与层级阴影标准。
      • 内置 HCT 动态色彩空间算法，输入单一主色相（0-360°）自适应推导全站色阶。
      • 搭载全新二次元 Chibi 芙宁娜 (Furina) 水元素无缝平滑循环 Loading 动效与交互。

      #3. 三级阅读权限与积分商城

      • 公开 (Public)：全网畅读。
      • 登录专属 (Login Required)：毛玻璃密码锁卡片。
      • 积分解锁 (Points Required)：博主自定义所需积分，读者通过每日签到积攒点数永久解锁，附带五彩纸屑粒子动效。

      #4. 50 款精美二次元 WebP 预设头像

      • 全新生成 50 款完全独特的二次元动漫头像与高清缩略图，提供便捷网格弹窗选择器。

      #5. 沙箱隔离的 Pio Live2D 看板娘

      • 采用独立 iframe 沙箱彻底隔离渲染环境，杜绝样式污染与脚本冲突。
      • 顶部常驻呼唤按钮与多语言自定义台词。

      #6. 多源音乐播放器

      • 支持本地曲目、R2 音频直链与 Meting 远端歌单（网易云、QQ 音乐、酷狗等）。
      • 引入音频元数据即时预载（preload="metadata"），杜绝时长延迟。

      #7. AI 写作辅助助手

      • 深度集成大语言模型流式输出，支持思维链推理（Reasoning / Thought）折叠推演与超时异常保护。
