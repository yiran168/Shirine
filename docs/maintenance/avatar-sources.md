# Shirine 头像素材来源

用户头像库共 50 位不同番剧角色，来自 8 部作品，各一张完整图（384×384 WebP）及一张缩略图（96×96 WebP）。图片保留原有场景或装饰背景，按圆形头像中的面部清晰度筛选。站长名片单独使用站长提供的芙宁娜图片。

每张用户头像来自下列官方 SNS 头像赠送页，保留原图版权标识。原著角色和图像的版权属于各作者与制作委员会，**不属于项目 MIT 许可**；这里不宣称这些素材为无版权素材或允许任意商业再分发。用途为本博客个人头像。

重建：在项目根目录运行 `node scripts/download-character-avatars.mjs`，下载缓存位于本项目 `.cache/anime-avatars`。脚本按源地址区分缓存，在完整校验 50 张素材后才替换正式目录。完整图和缩略图访问地址均记录于 `client/public/assets/avatars/avatars.json`。
