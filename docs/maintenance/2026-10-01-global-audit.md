## 本轮修复

1. **导航图标**：移除 1280–1439 像素断点隐藏 SVG 的规则；顶部导航图标采用独立 SVG 内容，避免 Swup 切换页面后引用的图标定义消失。
2. **音乐同步**：侧栏与右下角控件持有稳定的同一个控制器，封面优化和签名变化不再创建另一套播放实例；真正更换歌单时保留订阅关系。主动暂停后跨页不会自动恢复。修复悬停展开时切歌按钮移位导致点击落空。
3. **看板娘**：入口固定在左下角，空闲时降低透明度，交互时渐显；角色显示和收起使用淡入淡出。直接拖动角色，保存位置并共用于前后台；透明画布不再遮挡后台菜单。采样画布中角色的可见边界，将消息定位在头顶约 8 像素处。
4. **请求隔离**：SSR 内容缓存按 Request 隔离；语言通过请求上下文隔离，防止管理员草稿或语言状态串到其他请求。复制默认配置，避免修改共用默认对象。
5. **相册和积分**：统一列表、详情、密码验证、购买和图片访问的权限组合。密码通过不再绕过登录或积分条件；余额不足不再留下阻止重试的假账本记录；相册与照片原子保存，失败整体回滚。积分并发更新与返回余额保持一致。
6. **认证**：Cookie 名称精确匹配；CSRF 校验完整 origin；服务绑定保留公开站点 origin；注册和首次管理员创建采用原子条件插入。撤销会话失败时返回失败并保留客户端状态，避免假退出。公开的开发 JWT 密钥禁止用于生产。
7. **配置与媒体**：空集合保持为空，删除预设后不会自动补回；后台配置读取失败阻止保存默认值覆盖数据。媒体库保留带签名的代理地址、支持分页，上传失败数量如实显示。大音频仅允许管理员上传，校验文件类型和实际文件头。
8. **构建部署**：修复 JSONC 注释处理破坏 HTTPS 地址；生产配置剔除开发 JWT，密钥同步失败中止部署；构建使用 Node 24 和锁文件。头像清单移入源码供组件导入；图片直接使用已准备的 WebP，避免错误的 SSR 图片转换响应。

## OAuth、邮箱注册及可选手机号注册（2026-10-02）

本节为上述历史检查后的最终增量验证结果。

- 加入 Microsoft、Apple、GitHub、Google、QQ、Facebook、X / Twitter、Discord、微信、飞书、GitLab.com 共 11 种 OAuth 登录。后台逐项配置和启用，前台只展示已启用且配置完整的平台。授权成功返回原页面，首次注册仅创建普通用户，不按第三方邮箱或昵称合并已有账号。
- 普通注册默认要求邮箱、用户名和密码。邮箱验证码开关默认关闭；开启后必须完成邮箱验证码。手机号注册为独立开关，默认关闭；开启后才显示注册方式选择，且必须验证短信、不要求邮箱。第三方注册不附加本站邮箱或短信验证码。
- 邮件支持阿里云邮件推送、腾讯云 SES、SendCloud、Resend、SendGrid、Mailgun、Postmark、Brevo、SMTP2GO 和普通 SMTP。腾讯云使用已审核模板；阿里云签名匹配官方测试向量。SMTP 支持 465/994 隐式 TLS、587 强制 STARTTLS，认证只在加密后发送，无明文降级或 25 端口；提供 QQ、163、126 及常用企业邮箱的可编辑服务器提示。

- Turnstile 对普通登录、邮箱注册、手机号注册、OAuth 登录及首次注册均执行服务端校验；发送邮箱/短信验证码前也必须验证。发送后重置组件获取新令牌，手机窄容器使用 compact 模式，避免水平溢出。
- OAuth 状态一次使用、限时、绑定浏览器与平台；支持的平台使用 PKCE，OIDC 校验签名、issuer、audience 和 nonce。Apple 跨站 POST 回调仅对准确路径作 CSRF 特例，并保留状态及浏览器校验。平台配置改变会使进行中的授权失效。

## 全局交叉回归与安全复查（2026-10-03 至 2026-10-04）

基线 `2d3dd85` 已在 GitHub 完成 CI、站点部署和文档部署。本轮进一步覆盖认证、浏览器状态、积分日期、受保护内容、R2、音乐、移动端层级及依赖；业务写入仍全部使用本地测试库。

### 修复与验证

1. **Cookie 登录和浏览器存储**：浏览器禁用或耗尽 localStorage 时，Cookie 登录、后台初始化、头像、语言、主题和权限提示继续工作。偏好仅在当前浏览器内存降级保存，不在 SSR 进程中共享；Swup 跳转也使用同一份降级状态。旧的 `/me` 请求不能覆盖后续登录或退出的结果。
2. **注册与登录一致性**：邮箱注册接受的最长 254 字符标识可以正常登录。媒体地址清理只修改媒体/正文等明确字段，不再意外改写与旧头像路径相同的密码或其他凭据。
3. **签到状态**：菜单、个人资料和签到接口使用相同站点时区；非法时区安全回退。连续签到按日历日计算，避免夏令时切换日以 24 小时倒推造成重复日期。
4. **受保护文章**：历史数据即使只有“密码访问”标记而缺失密码，也拒绝公开正文和关联 R2 文件；保存时拒绝无有效密码的保护状态。列表、详情、密码验证与媒体访问采用一致判断。
5. **登录尝试限制**：普通登录每 IP 每分钟 20 次，普通注册每 IP 每 10 分钟 10 次，开关 Turnstile 均生效。D1 原子计数防止并发绕过；过期恢复，配额存储故障时拒绝认证而非放行。限额按接口隔离，存储键不含明文 IP。
6. **R2 地址与权限**：外站头像/图片即使路径与桶对象相同，也不能被当作该文件已公开的证据；外站伪造 `/api/blob/` 路径同样无效。配置的存储基地址带路径前缀时，正常发布图片仍可访问。所有权限检查保持在读取 R2 对象之前，异常时拒绝访问。
7. **长时间停留后的音乐播放**：续播或切换至已过期的 R2 音频地址时先续签，实际媒体请求仍重新检查访问权限；续签失败停止并显示错误，不无限跳歌。重新加载同一曲目保留播放位置；播放器销毁和主动暂停清除浏览器自动播放补救监听，避免旧实例突然发声。
8. **移动端看板娘**：自由拖动后仍位于导航和账户菜单下方，避免挡住登录、注册等操作；前后台分别适配原有层级。浏览器命中测试确认重叠位置点击的是账户菜单。

### R2 防盗用边界

上一轮正式部署已通过 Cloudflare API 确认 R2 的 `r2.dev` 和自定义公开域名均关闭，只保留 Worker 绑定访问；部署脚本继续检查两种入口。两种公开入口相互独立，不能只关其中一种。[Cloudflare 官方说明](https://developers.cloudflare.com/r2/buckets/public-buckets/)。

前台使用短期签名代理地址，受保护文件同时校验实时账号/解锁/密码授权；跨站浏览器热链在数据库和 R2 访问之前拒绝。但访问者能够下载已经向其展示的公开图片，短期地址也可能在有效期内被复制；请求头不能阻止模拟客户端。这里减少直接盗链和绕过权限的风险，不承诺“公开图片永远无法被复制”或完全避免恶意请求费用。持续攻击需要站点域名上的 Cloudflare 限流/WAF 和用量监测配合。

- 媒体库依次读取全部分页，按上传时间降序显示；搜索覆盖完整列表，卡片每次只渲染 100 个。修复“刷新”把点击事件误当成追加分页参数的问题；重复刷新、离开组件及上传与刷新并发时，旧请求不能覆盖新结果。
