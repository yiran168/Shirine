# 简介

Shirine 是一个基于 Astro 5 与 Cloudflare 全栈架构（Cloudflare Pages SSR + Workers + D1 分布式数据库 + R2 对象存储）的高性能二次元美学动态博客系统，深度融合 Material 3 Expressive (M3E) 设计规范。

## 开源仓库

- GitHub: [https://github.com/yiran168/Shirine](https://github.com/yiran168/Shirine)

## 核心特性

1. **Material 3 Expressive 设计系统**：100% 遵循 Google M3E 大圆角流体布局与层级阴影，内置 HCT 动态色彩算法，调节主色相（0-360°）即可自动派生全站合规色阶。
2. **全动态即时发布（即写即看）**：前端基于 Astro 5 SSR，后端基于 Cloudflare Workers + Hono + Drizzle ORM；数据持久化于 Cloudflare D1，附件存储于 Cloudflare R2。后台发布博文、新建相册或发布动态日记，前台刷新即刻可见。
3. **三级阅读权限与积分商城**：支持公开畅读、登录专属（毛玻璃锁面）与积分解锁（自定义所需积分，通过签到积攒点数永久解锁并伴随五彩纸屑粒子动效）。
4. **每日签到与积分奖励引擎**：支持固定点数与区间随机抽奖模式，精准记录连续打卡天数与资产明细。
5. **50 款精选二次元 WebP 预设头像**：内置 50 款精美动漫头像（含高清与缩略图），支持网格弹窗自由切换，自适应访客、用户与管理员三种状态。
6. **沙箱隔离的 Pio Live2D 看板娘**：使用独立 iframe 沙箱彻底隔离渲染环境，杜绝样式污染；支持前台与后台独立开关、自定义多语言台词与无遮挡顶层层级。
7. **多源音乐播放器**：支持本地预设、R2 自定义音频直链以及 Meting 云端歌单（网易云、QQ 音乐、酷狗等），音频元数据即时预载，杜绝时长延迟。
8. **丰富 Markdown 语法生态**：内置提示框 (Admonition)、步骤容器 (Steps)、折叠面板、代码分组、Mermaid 架构图、KaTeX 数学公式及音视频嵌入。
9. **AI 写作辅助助手**：支持流式生成与折叠式思维链（Reasoning / Thought）推演，提供优雅的请求超时兜底。
10. **Cloudflare Turnstile 智能人机防护**：全站无感人机验证，抵御恶意刷单与暴力破解。
11. **四语言完整国际化 (i18n)**：全站及管理后台完整支持简体中文、繁体中文、英语、日语无缝切换。
12. **RSS 2.0 & Atom 1.0 全文订阅**：内置智能权限过滤机制，保护私密内容不被公共聚合源泄露。
