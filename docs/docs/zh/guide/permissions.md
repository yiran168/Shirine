# 用户、权限与积分体系

Shirine 内置了一套完整的用户成长与内容权限控制系统，使博客既能作为博主个人的精致展示窗口，也能作为高粘性的二次元兴趣社区。

---

## 一、用户角色与首位注册机制

系统内置 3 种用户角色：
1. **超级管理员 (`superadmin`)**：
   - 具有全站最高控制权。
   - **首位注册机制**：当数据库中没有任何用户时，第一个注册的用户将**自动且无条件**成为 `superadmin`。
   - 可在管理后台调整全站设置、分配积分、提拔管理员及封禁违规账号。
2. **管理员 (`admin`)**：
   - 具备博文、相册、动态日记发布与修改权限，以及友链审核权限。
3. **普通用户 (`user`)**：
   - 默认注册角色。享有每日签到、积分解锁专属博文/相册、评论互动及更换预设二次元头像等功能。

---

## 二、全局导航栏头像与 20 款预设二次元头像

在 Shirine 博客全局顶栏右上方，常驻一枚圆形头像按钮。它根据三种状态动态自适应呈现：

### 1. 未登录状态 (Guest)
- 头像显示简约访客图标。
- 点击展开下拉菜单，提供两个选项：
  - **登录**：弹出登录弹窗（支持 Turnstile 人机验证）。
  - **注册账号**：弹出注册弹窗。

### 2. 普通登录用户 (User)
- 头像显示当前选中的自定义动漫头像。
- 展开菜单从上至下依次为：
  1. **每日签到**：点击后执行打卡逻辑，签到成功后触发礼花粒子动效并提示本次获得的积分与连签天数。
  2. **更换头像**：打开 20 款预设动漫 WebP 头像网格弹窗，即点即换并即时持久化到数据库。
  3. **退出登录**：安全清除身份令牌并刷新状态。

### 3. 管理员状态 (Admin)
- 头像带有高亮环绕光晕。
- 展开菜单从上至下依次为：
  1. **管理面板**：一键直达 `/admin` 可视化控制台。
  2. **更换头像**：更换管理员头像。
  3. **退出登录**。

## 三、每日签到与积分发放引擎

管理员可在后台 **系统与设置** -> **每日签到与积分引擎规则** 中灵活设定签到模式：

| 模式 | 配置参数 | 逻辑说明 |
| :--- | :--- | :--- |
| **固定积分模式 (Fixed)** | `checkinFixedPoints` (如 10) | 每次打卡固定增加 10 点积分，简单明确。 |
| **随机区间模式 (Random Range)** | `checkinRandomMin` ~ `checkinRandomMax` (如 5 ~ 25) | 每次打卡在 $[min, max]$ 闭区间内由密码学安全随机函数生成获得的积分，趣味感十足。 |

- **防重入与时区判定**：以配置的时区（默认 `Asia/Shanghai`）零点为周期，每人每天仅可打卡一次。
- **连续签到记录**：若昨日已签到，连续签到天数自动累加；若断签则重置为 1，激励读者每日造访。

## 四、内容三级阅读权限

Shirine 在文章（Posts）与相册（Albums）维度均支持三级细粒度权限控制：

### 1. 🟢 完全公开 (Public)
无需登录，全球任意访客直接畅读全文或浏览相册大图。

### 2. 🟡 登录专属 (Login Required)
- **卡片列表展示**：文章封面与相册卡片覆盖磨砂毛玻璃锁层，标题旁标注黄色锁徽章。
- **详情页阻断**：正文内容被隐藏，居中展示优雅的会员登录引导卡片，访客登录后无需刷新即可阅读。

### 3. 🟣 积分解锁 (Points Required)
- **自定义所需积分**：博主在后台可为每篇文章或相册单独设置所需解锁积分点数（例如 `50` 积分）。
- **永久解锁机制**：用户使用日常签到获得的积分点击解锁后，系统在 D1 数据库中建立事务级解锁关联记录，此后该用户无论何时何地登录均可**无限次永久阅读**，无需重复扣分。
- **原子事务与防刷**：扣除积分与写入解锁记录在单个 SQL 事务中执行，积分不足时前端引导用户前往打卡签到。
