# 管理后台与实时更新 (Admin Console)

Shirine 提供了沉浸式、极简响应式的管理控制台（`/admin`），深度整合全栈能力。

---

## 一、即写即看（无构建发布）

在传统的静态博客（如 Hexo、Hugo 或原生 Astro 静态站）中，博主撰写文章后必须提交 Git 仓库并触发云端构建流水线，等待 3-5 分钟才能看到新文章。

Shirine 采用现代全动态服务端渲染（SSR）架构：
1. 博主在管理控制台点击 **“保存并发布”**。
2. 数据直接写入 Cloudflare D1 边缘数据库，图片即时存储在 Cloudflare R2。
3. 返回博客前台**按下刷新（F5）**，最新发表的文章或修改的内容**立即可见**！

---

## 二、功能模块详解

### 1. 📊 仪表盘概览
- 展示全站核心数据指标卡片：文章总数、相册总数、动态总数、注册用户总数及全站流通积分总数。
- 提供一键发布文章、相册与系统设置的快捷入口。

### 2. 📝 博文管理
- **列表视图**：支持快速查看所有文章的标题、固定链接别名（Slug）、分类、标签、发布日期及权限类型。
- **文章编辑器**：
  - 支持置顶（Pinned）开关；
  - 自由设定分类与逗号分隔的标签体系；
  - **权限与积分**：下拉选择“完全公开”、“需登录”或“积分解锁”，并配置扣减点数；
  - **封面上传**：可直接输入外部图片 CDN 链接，或点击按钮将图片直传至 Cloudflare R2 对象存储；
  - **Markdown 正文**：提供宽屏 Markdown 编写区域，完美支持各类富文本语法与短代码。

### 3. 🖼️ 相册图库
- 适合摄影、插画、同人图及日常照片展示。
- 支持设置相册标题、描述、封面、布局样式（瀑布流 Masonry / 网格 Grid）与展示列数。
- 支持每张相片独立设置说明文字，并可独立设定相册的查看权限。

### 4. 💭 动态日记 (Moments)
- 类似即刻、朋友圈的极简碎片生活记录。
- 快捷输入框支持选择心情表情（如 ✨/🌸/🍰）、打卡地理位置及上传多张照片。

### 5. 🔗 友链管理
- 支持前台访客自主申请友链，后台审核流管理。
- 管理员可一键“批准通过”或“删除”申请，也可主动录入新友链。

### 6. 👥 注册用户与积分管理
- 集中展现所有注册用户列表。
- **调整积分**：管理员可输入任意增减数值（如 `+50` 或 `-20`）为指定用户派发积分奖励。
- **角色任命**：支持在 `admin` 与普通 `user` 角色之间一键切换。
- **安全封禁**：对恶意违规用户执行封禁，禁止其打卡与解锁资源。

### 7. ⚙️ 全站与系统设置
- **签到积分规则**：选择固定积分或区间随机模式，设定具体数值。
- **Turnstile 验证**：开启/关闭人机验证，配置 Site Key 与 Secret Key。
- **看板娘开关**：独立控制访客前台与后台管理界面是否加载 Live2D 看板娘。
- **主题与外观**：实时调节 Material 3 主色相（0-360°）与顶栏对齐方式。
