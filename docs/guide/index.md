# Shirine 简介

**Shirine** 是一款专为二次元与极客爱好者打造的高颜值、现代动态博客系统。

它深度融合了 Google Material 3 Expressive (2025) 极致优雅的设计语言与强大的无服务器（Serverless）动态全栈架构，彻底告别了传统静态博客“修改内容必须触发 CI/CD 重新全量构建数分钟”的痛点。

---

## 🌟 核心特性

- **视觉与交互**：
  - 100% 保持 Material 3 Expressive 大圆角规范、柔和阴影、弹性微动效。
  - HCT 动态色彩空间算法，基于主色相（0-360°）自适应生成全套对比度合格的情境调色板。
  - 丰富的 Markdown 扩展：提示框 (Admonition)、步骤容器 (Steps)、折叠面板、代码组、Mermaid 图表、KaTeX 数学公式、音频与 Bilibili 播放器。

- **动态全栈架构**：
  - **前端**：Astro 5 + Svelte 5 + Tailwind CSS 4，配置 Cloudflare 适配器与 SSR，毫秒级边缘渲染。
  - **后端**：Cloudflare Workers + Hono 极速 Web 框架 + Drizzle ORM，纯边缘低延迟。
  - **存储**：Cloudflare D1 分布式 SQLite 数据库存储文章、相册、日记与用户；Cloudflare R2 存储文章插图、相册原图与附件。
  - **即写即看**：后台发布或更新内容，前台博客刷新立刻直呈，体验极其丝滑。

- **用户与积分体系**：
  - **自动超级管理员**：系统首位注册的用户自动获得 `superadmin` 权限，免去手动配置数据库的繁琐。
  - **每日签到引擎**：支持管理员灵活配置：
    - **固定积分模式**：每次签到发放固定积分（如 10 积分）。
    - **区间随机模式**：在 $[min, max]$ 范围内随机抽取积分，增强趣味性。
  - **连签天数记录**：实时记录用户连续签到天数与累计签到统计。

- **三级内容阅读权限**：
  - 🟢 **完全公开 (Public)**：全网访客自由阅读。
  - 🟡 **登录专属 (Login Required)**：访客需注册并登录后方可阅读；未登录时封面带有毛玻璃锁遮罩，进入页面提示登录卡片。
  - 🟣 **积分解锁 (Points Required)**：需消耗指定积分永久解锁；未解锁时前台展示积分扣除卡片与积分余额，点击解锁触发五彩纸屑粒子动画并完成事务级扣分。

- **全局导航栏头像菜单**：
  - 顶部导航栏右上角圆形头像交互入口，自适应三种状态：
    - **未登录**：访客头像，展开登录 / 注册入口。
    - **普通用户**：个人头像，展开每日签到、更换头像、退出登录。
    - **管理员**：个人头像，展开管理控制台入口、更换头像、退出登录。
  - 内置 **20 款预设二次元 WebP 头像**，支持网格弹窗一键切换。

- **Pio Live2D 看板娘**：
  - 基于 Mizuki 的看板娘实现，采用 iframe 沙箱独立隔离挂载，彻底杜绝样式与脚本冲突。
  - 支持前台访客与后台管理员独立开启控制，并在页面右下角提供折叠唤起小按钮。

- **Cloudflare Turnstile 防护**：
  - 集成 Cloudflare 最新人机验证方案，无感验证，后台一键开关及密钥配置。
