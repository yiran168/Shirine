# Admin Console

Shirine provides an all-in-one management dashboard located at `/admin`.

---

## Key Features

1. **Dashboard Overview**: Key metrics (posts, albums, moments, users, circulating points) and quick action shortcuts.
2. **Posts Management**: Full-featured Markdown editor, tags, categories, R2 cover uploads, and 3 permission tiers.
3. **Albums Management**: Gallery creation with Masonry or Grid layout, photo uploads, and point access options.
4. **Moments**: Quick journal updates with mood emoji, geolocation, and photos.
5. **Friend Links**: Review and approve visitor submissions.
6. **User Management**: Adjust point balances, change user roles, and ban/unban users.
7. **System Settings**: Configure check-in point rules, Cloudflare Turnstile, Live2D widget toggles, and site theme.
